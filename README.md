# Медвежий Рыцарь: Тьма Севера

Дарк-фэнтези платформер: рыцарь в медвежьем доспехе идёт через пять земель к Медвежьему Королю.
Запускается в обычном браузере и как Telegram Mini App. Ни сборки, ни зависимостей — чистый
JavaScript, Canvas 2D и процедурная графика (спрайтов и картинок в проекте нет вообще).

## Что внутри

- **Платформер-бой**: лёгкая и тяжёлая атака с комбо, выносливость, рывок с неуязвимостью,
  двойной прыжок, отскок платформ, костры-чекпоинты.
- **Пять земель** с процедурной генерацией по сиду: Иссохший лес, Пепельная деревня,
  Багровые катакомбы, Пепельные пустоши, Цитадель. Одинаковый сид — одинаковая карта.
- **Враги и боссы**: гули, скелеты, лучники, чернокнижники, костоломы, кровососы, плюс
  Страж Оссуария и Медвежий Король с фазами, рывками, залпами и призывом слуг.
- **Лут**: с врагов и из сундуков падает золото, души и предметы пяти редкостей.
  Шанс редкого лута растёт от сложности земли и умения «Жатва душ».
- **Магазин**: оружие (мечи, кинжалы, топоры, молоты), броня четырёх слотов, зелья, продажа хлама.
- **Дерево прокачки**: три ветки по семь узлов — Урса (сила), Ловчий (ловкость), Умбра (тьма).
  Души тратятся на ранги, часть узлов открывает активные способности.
- **Сохранение**: автоматически у каждого костра, при выходе с уровня, покупке и смерти.

## Запуск в браузере

```bash
npm run dev
```

Откроется http://localhost:4173. Файл `index.html` можно открыть и напрямую, но модули
загружаются только по http, поэтому лучше через сервер.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | `A` / `D` или стрелки |
| Прыжок (и двойной) | `W`, `↑`, `Space` |
| Спрыгнуть с платформы | `S` + прыжок |
| Атака / тяжёлый удар | `J` / `K` |
| Рывок | `Shift` |
| Рёв Урсы / Теневой сгусток | `Q` / `E` |
| Зелье | `R` |
| Костёр, сундук, портал | `F` |
| Пауза | `Esc` |

На телефоне управление экранными кнопками — они появляются автоматически на сенсорных
устройствах.

## Telegram Mini App

Игра сама определяет, что запущена внутри Telegram: разворачивает окно, красит хедер, включает
вибро-отклик и переносит сохранение в **CloudStorage**, привязанный к аккаунту. Вне Telegram тот
же сейв лежит в `localStorage`, так что игра полностью работает и в обычном браузере.

### 1. Выложить игру на https

Mini App открывается только по https. Подойдёт любой статический хостинг: GitHub Pages,
Cloudflare Pages, Netlify, Vercel. Для локальной проверки можно поднять туннель, например
`npx --yes localtunnel --port 4173`.

### 2. Поднять бота

```bash
cd bot
npm install
cp .env.example .env   # в PowerShell: copy .env.example .env
# впиши BOT_TOKEN от @BotFather и WEBAPP_URL со своим https-адресом
npm start
```

Бот выдаёт кнопку «Играть» под сообщением и в меню рядом с полем ввода. Обе открывают игру
внутри Telegram.

## Структура

```
index.html          разметка, канвас и экранные кнопки
styles.css          интерфейс, меню, адаптив под телефон
src/
  main.js           запуск: сохранение, ввод, игра, интерфейс
  core/             утилиты, ввод, синтез звука, Telegram, сохранение
  data/             предметы, дерево умений, враги, земли
  game/             мир и коллизии, сущности, бой, лут, рендер, HUD
  ui/               лагерь, магазин, снаряжение, дерево умений, иконки
bot/                Telegram-бот с кнопкой Mini App
```

Отладка: в консоли браузера доступен `window.bearKnight` (`game`, `ui`, `save`).

## Баланс в двух словах

Урон = урон оружия × множители умений, крит по шансу, броня режет входящий урон по формуле
`armor / (armor + 90)`. Души — валюта прокачки, золото — валюта магазина. Смерть отнимает 20%
золота, души остаются. Возрождение — у последнего зажжённого костра.
